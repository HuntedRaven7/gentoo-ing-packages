# gentoo-ing-packages

Curated Gentoo **binary package host (binhost)** for
[`gentoo-ing`](https://github.com/HuntedRaven7/gentoo-ing) — the "utah-packages"
of this factory.

It publishes a data-only OCI image whose *only* content is a binhost tree:

```
/var/cache/binhost/gentoo-ing/
├── Packages                 # index, regenerated by emaint binhost --fix
├── sys-kernel/
│   └── gentoo-kernel-bin-*.tbz2
├── app-containers/
│   └── podman-*.tbz2
└── ...
```

`gentoo-ing` consumes it with `COPY --from=` pinned by digest and configures it
in `binrepos.conf` at `priority = 1`, with the official Gentoo binhost as the
low-priority (`9959`) fallback. Anything dropped into `packages/` here wins
over upstream — that is the whole point.

## How it works

- `packages/` is the binary cache. Drop in `.tbz2` files — see
  [docs/adding-packages.md](docs/adding-packages.md).
- The `Containerfile` copies `packages/` into an indexer stage and runs
  `emaint binhost --fix` to (re)generate the `Packages` index, then publishes
  only the binhost tree to `scratch`.
- `main` publishes `ghcr.io/HuntedRaven7/gentoo-ing-packages:latest` plus a
  `:gitsha` tag. Pull requests build and validate only — never publish.
- Consumers pin the image by digest (Renovate tracks the digest in the
  consuming `Containerfile`'s `FROM` line).

## Usage

```bash
just validate            # sanity checks config + package tree
just build               # build the image locally
just push                # push ghcr.io/HuntedRaven7/gentoo-ing-packages:latest
just seed                # pull the curated official set into packages/
just show-package-set    # print config/packages.txt
```

## Adding a package

1. Build it (or fetch it) and drop the `.tbz2` into `packages/<category>/`.
2. (Optional) add it to `config/packages.txt` so the seed tool keeps it fresh.
3. `just validate`, commit, push.
4. CI rebuilds + publishes `:latest`. The next `gentoo-ing` build picks it up.

See [docs/adding-packages.md](docs/adding-packages.md) for options A–C and the
full walkthrough.

## Initial setup

1. (Recommended) seed the overlay: `just seed`
2. Build once so a digest exists for `gentoo-ing` to pin:
   `just build && just push`
3. Copy the resulting digest into the `gentoo-ing` `Containerfile`:
   `podman inspect ghcr.io/HuntedRaven7/gentoo-ing-packages:latest --format '{{index .RepoDigests 0}}'`

The seed tool is intentionally granular: the overlay mirrors `x86-64`/`23.0`,
matching the `gentoo/stage3:systemd` base used by `gentoo-ing`.

# The FULL gentoo-ing OS build set, mirror of build/10-build.sh PACKAGES in the
# gentoo-ing repo plus sys-kernel/installkernel (a dependency of the kernel the
# consumer resolves with USE=dracut, which the official binhost cannot serve).
#
# This repo is the consumer's ONLY source of packages: gentoo-ing is wired to
# this overlay exclusively (--usepkgonly --binpkg-respect-use=y) and never
# touches the official binhost at runtime.
#
# The maker resolves this set with --getbinpkg: when the official Gentoo
# binhost carries the atom, its prebuilt binary is mirrored into this overlay
# (same USE, same profile); when it does not (bootc, kernel, firmware, skopeo,
# flatpak, iwd, jq, installkernel, gum, just), the atom is compiled here. Every
# merged package -- atoms AND their dependency closure -- is re-emitted with
# --buildpkg, so the overlay is fully self-contained and the consumer never
# needs any binrepo but this one.
#
# Three of the atoms (sys-apps/bootc, app-shells/gum, dev-util/just) have no
# ebuild in ::gentoo at all; their live ebuilds live under ebuilds/ in this
# repo and are exported to consumers for atom visibility.
#
# Format: one unslotted atom or category/package pattern per line. '#' is a
# comment. Keep this list in sync with gentoo-ing/build/10-build.sh
# (tools/sync-check.py asserts the parity in CI).

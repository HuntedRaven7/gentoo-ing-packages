# Dependency-ordered build stages for the Build Matrix workflow (utah-packages
# model). Each stage is a matrix that builds its atoms in parallel; a stage-N
# edge resolves an intra-set dependency against the artifacts of stages < N
# (registered as a local binrepo above the official Gentoo host), so a compiled
# gap is built once and reused by everything above it instead of being
# recompiled by every downstream edge.
#
# Format: one `STAGE<TAB>atom` pair per line. '#' is a comment. An atom MISSING
# from this file defaults to stage 0 — the default is safe, only wasteful: an
# edge that cannot find one of this factory's compiled gaps in /prior simply
# compiles it itself. When you add an atom to config/packages.txt, give it the
# earliest stage whose dependencies are satisfied by the available states.
#
